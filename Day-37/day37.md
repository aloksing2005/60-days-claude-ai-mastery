# Day 37 – Task Compass

## Challenge
Build an interactive organizational learning application called **Task Compass** that teaches how work flows through real organizations.

## Workplace Selected
Hospital / Healthcare

---

# Objective

The objective of this project was to understand:

- Ownership
- Delegation
- Collaboration
- Workflow Thinking

through an interactive management simulation instead of a traditional quiz.

---

# Features

- Three Interactive Learning Stages
- Drag and Drop Role Assignment
- Task Routing Workflow
- Collaboration Challenges
- Organizational Thinking Dashboard
- Progress Tracking
- Glassmorphism UI
- Responsive Design
- Offline Support
- Pure HTML, CSS and JavaScript

---

# Stage 1 – Who Owns This?

In this stage, different workplace tasks were presented.

I selected the most appropriate department or role responsible for completing each task.

After every answer, the application explained:

- Primary Owner
- Supporting Roles
- Reasoning

---

# Stage 2 – Task Routing

This stage focused on workflow management.

I arranged departments in the correct order to complete organizational tasks.

The simulation demonstrated how work moves through multiple teams.

---

# Stage 3 – Collaboration Challenge

Complex workplace situations required collaboration among multiple departments.

Instead of selecting only one owner, I assigned several supporting teams and reviewed the recommended communication flow.

---

# Organizational Thinking Dashboard

The final dashboard evaluated my understanding in four areas:

- Ownership
- Delegation
- Collaboration
- Workflow Thinking

The dashboard also generated personalized reflections about my decision making.

# Key Learnings

- Learned how ownership differs from collaboration.
- Understood how work flows through multiple departments.
- Improved workflow thinking.
- Learned task delegation concepts.
- Experienced real organizational decision making.
- Understood the importance of communication between teams.

---

# Conclusion

Task Compass provided an engaging way to understand organizational workflows through realistic scenarios and interactive gameplay. The experience demonstrated that successful organizations rely on clear ownership, effective delegation, and strong collaboration rather than individual effort alone.
