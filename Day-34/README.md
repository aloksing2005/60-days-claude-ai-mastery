# Day 34 – Marketing Detective

## Challenge
60-Day Claude AI Mastery Challenge

## Theme
Marketing, Consumer Psychology & Critical Thinking

## Objective
Build an interactive Marketing Detective application that helps users investigate fictional marketing campaigns, identify mistakes, and understand why campaigns succeed or fail.

## Features
- Theme Selection
- Random Campaign Generator
- Evidence Board
- Budget Analysis
- Audience Analysis
- Customer Feedback
- Engagement Dashboard
- Root Cause Investigation
- Drag & Drop Clues
- Marketing Learning Report
- Replay Feature

## Technologies
- React (CDN)
- HTML
- CSS
- JavaScript
- Claude AI

## Learning Outcomes
- Marketing analytics
- Consumer psychology
- Campaign investigation
- React-based frontend development
