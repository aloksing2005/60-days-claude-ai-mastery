# Day 39 – PDF Splitter & Merger

## Objective

Built a browser-based PDF utility using Claude AI.

---

## Features

- PDF Splitter
- PDF Merger
- Drag & Drop Upload
- Page Preview
- Split by Range
- Split Every N Pages
- Extract Selected Pages
- Merge Multiple PDFs
- Reorder PDFs
- Download Processed PDFs
- Responsive Design
- Dark Mode
- Offline Support

---

## Technologies Used

- HTML5
- CSS3
- JavaScript
- PDF.js
- PDF-Lib
