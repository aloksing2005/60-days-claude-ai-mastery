What is the Personal AI Playbook?

This is a personal toolkit for building reusable AI prompt systems instead of retyping prompts from scratch every time. It's built around your use cases: studying & exam prep, research & literature review, and coding & data analysis.

  • Workflows — ready-made, editable prompt templates organized by task, with one-click copy.
  • Prompt Builder — assemble a custom prompt from labeled building blocks (role, objective, context, etc.) with a live preview, so you learn the anatomy of a good prompt.
  • Loop Builder — turn any prompt into a self-checking, iterative "loop" prompt with goals, evaluation criteria, and stop conditions.
  • My Workflows — anything you save, favorite, or create yourself, stored in this browser only (local storage).
