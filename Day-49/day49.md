# Day 49 — Personal AI Playbook

## Project
Built a personalized AI workflow system using Claude.

## What I Built
- Personalized AI workflow library
- Prompt Builder
- Autonomous Loop Builder
- Reusable prompt building blocks
- Workflow search and filtering
- Save, edit, duplicate and favorite workflows
- Local storage
- Import/export functionality
- Dark mode and responsive UI

## My AI Profile
- Role: B.Tech CSE student
- Primary use: Coding, studying, research, problem solving
- AI experience: Intermediate
- Main AI models: Claude, ChatGPT, Gemini
- Main bottleneck: Rewriting similar prompts repeatedly
- Main goal: Learn to design better AI workflows

## Key Learnings
1. Reusable prompt blocks are better than one-off prompts.
2. AI workflows can be structured around repeatable tasks.
3. Prompt Builder helps create consistent prompts.
4. Loop Builder can turn a normal prompt into an iterative workflow.
5. Good AI systems need clear objectives, context, constraints and quality checks.
