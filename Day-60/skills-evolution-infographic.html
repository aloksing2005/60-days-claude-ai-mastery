The Convergence

RoundsAI — an AI doctor workflow platform

Requirements → Design → Setup → Implementation → Testing → Deployment. A single 10-day sprint that required every capability built across the preceding fifty days — not as separate skills, but working together under real constraints.

Prompt Engineering
A strict, safety-bounded system prompt constraining Claude to summarization only — never diagnosis.
Product Thinking
A locked PRD and scope boundary held for all nine build days — no drift, no unscoped features.
Reliability Engineering
A fallback architecture designed before it was needed — then proven against a real live API failure.
Full-Stack Execution
React, Node/Express, MongoDB, JWT auth — designed, built, and deployed end-to-end.
Security Judgment
Audited unfamiliar commits line-by-line and corrected a real vulnerability before public launch.
Production Discipline
Verified via a 23-point checklist run directly against the live URL — not just localhost.

Where the Learning Showed Up — Not in Theory, in the Build

Day 6
The Claude API returned a real "insufficient credit balance" error in production. The fallback — designed in advance, not improvised — caught it and produced a clearly labeled summary instead of a crash.
Day 8
A live end-to-end walkthrough surfaced a genuine release-blocking gap in visit creation. It was root-caused, fixed minimally and idempotently, and re-verified — the same day.
Day 9
Three unexplained commits were found in the git history. Rather than trust or revert blindly, each was audited file-by-file — surfacing and fixing a real JWT-in-localStorage exposure before launch.
