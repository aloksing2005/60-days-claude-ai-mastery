# Day 40 – AI Assistant Builder

## Objective

Built a production-ready AI Assistant using Claude AI.

---

## Assistant Details

**Assistant Name**

Hospital Management Assistant

**Target Users**

- Patients
- Doctors
- Hospital Administrators

**Primary Goal**

Provide healthcare assistance, appointment guidance, hospital information, and patient support through an AI-powered conversational interface.

---

## Features

- Interactive Chat
- Responsive UI
- Modern Dashboard
- Documentation Panel
- Loading Animation
- Error Handling
- Multi-turn Conversation
- Professional Theme
- Mobile Responsive

---

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Claude API Integration

---

## System Prompt

The assistant is designed to act as a professional Hospital Management Assistant capable of helping users with hospital-related information, appointment guidance, and healthcare support while avoiding medical diagnosis.
